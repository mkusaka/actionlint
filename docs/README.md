Documents
=========

- [Checks](checks.md): Full list of all checks done by yactionlint with example inputs, outputs, and links to the external upstream playground.
- [Installation](install.md): Installation instructions for yactionlint. Prebuilt binaries, building from source, and a download
  script (for CI) are available. Package-manager distributions are explicitly marked as upstream actionlint.
- [Usage](usage.md): How to use `yactionlint` command locally or on GitHub Actions, plus external integrations for upstream actionlint.
- [Configuration](config.md): How to configure yactionlint behavior. Currently, only labels of self-hosted runners can be
  configured.
- [Go API](api.md): How to use the `actionlint` Go library.
- [References](reference.md): Links to resources.
